# Academy of Excellence - Student Portal (A.O.E)

A high-end, glassmorphic student portal for the "Academy of Excellence" (A.O.E). This application features a secure login system, performance analytics dashboard, and administrative management tools.

## 🚀 Live Demo
You can host this project on **GitHub Pages** using the provided scripts.

## ✨ Features
- **Frosted Glass UI**: High-end aesthetic with backdrop blurs and mesh gradients.
- **AI-Powered Sidekick**: Integrated Gemini AI assistant to help students track grades and schedules.
- **Performance Analytics**: Visual data trends using Recharts.
- **Responsive Navigation**: Seamless experience across mobile, tablet, and desktop.
- **Dual Portal Access**: 
  - **Student View**: Attendance, marks, tasks, and support.
  - **Teacher Panel**: Student registry, enrollment, and curriculum management.

## 🛠️ Local Development

1. **Clone the Repo**:
   ```bash
   git clone <your-repo-url>
   cd aoe-portal
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Environent Variables**:
   Create a `.env` file in the root and add your Gemini API Key:
   ```env
   VITE_GEMINI_API_KEY=your_api_key_here
   ```

4. **Run Dev Server**:
   ```bash
   npm run dev
   ```

## 📦 Deployment (GitHub Pages)

To deploy this project to your GitHub repository:

1. Update the `homepage` field in `package.json` to your GitHub URL:
   `"homepage": "https://<username>.github.io/<repo-name>"`
2. Run the deployment command:
   ```bash
   npm run deploy
   ```
